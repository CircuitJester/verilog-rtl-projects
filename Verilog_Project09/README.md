# Project 9 – CAN Bus Controller

## Overview

This project implements a simplified Controller Area Network (CAN) Bus Controller in Verilog HDL. The design demonstrates the fundamental building blocks of a CAN transmitter, including frame generation, bit stuffing, CRC generation, acknowledgement handling, and a finite state machine (FSM) that coordinates the complete transmission process.
The project is intended for learning RTL design, digital communication protocols, FPGA development, and verification.


## Features

- CAN Bit Timing Generator
- CAN Frame Generator
- CAN Bit Stuffing Unit
- CAN CRC Generator (Educational Version)
- CAN ACK Generator
- CAN Transmit FSM
- Top-Level CAN Controller Integration
- Complete System Testbench
- Simulation Support


## Learning Outcomes

- CAN protocol fundamentals
- Modular RTL design
- FSM-based controller implementation
- Bit stuffing algorithm
- CRC-based error detection
- ACK mechanism
- Top-level module integration
- Functional simulation and verification
