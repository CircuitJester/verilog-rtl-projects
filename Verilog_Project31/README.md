# Project 31 — Return Address Stack (RAS)

## Overview

This project implements a small **Return Address Stack (RAS)** in Verilog HDL as a processor microarchitecture component for predicting function return addresses.

A Return Address Stack stores return addresses generated by function calls and provides the most recently stored address when a corresponding return instruction is encountered.

The structure follows a **Last-In, First-Out (LIFO)** organization:

```text
Function Call
     │
     ▼
 Push Return Address
     │
     ▼
 ┌──────────────────┐
 │ Return Address   │
 │      Stack       │
 │                  │
 │   8 Entries      │
 │   32-bit each    │
 └────────┬─────────┘
          │
          ▼
   Top Return Address
          │
          ▼
 predicted_return_address
```

The implementation contains an **8-entry stack**, with each entry capable of storing a **32-bit return address**.

The design supports:

- Push
- Pop
- Reset
- Empty detection
- Full detection
- Stack overflow protection
- Stack underflow protection
- Top-of-stack prediction

The project demonstrates how a relatively small hardware structure can assist instruction-flow prediction inside a processor.

The stack stores return addresses sequentially and exposes the current top entry as the predicted return address.

# Stack Organization

The implementation contains:

```text
Stack Depth  = 8 entries
Address Size = 32 bits
```

Conceptually:

```text
        +----------------------+
Entry 7 | 32-bit Return Addr. |
        +----------------------+
Entry 6 | 32-bit Return Addr. |
        +----------------------+
Entry 5 | 32-bit Return Addr. |
        +----------------------+
Entry 4 | 32-bit Return Addr. |
        +----------------------+
Entry 3 | 32-bit Return Addr. |
        +----------------------+
Entry 2 | 32-bit Return Addr. |
        +----------------------+
Entry 1 | 32-bit Return Addr. |
        +----------------------+
Entry 0 | 32-bit Return Addr. |
        +----------------------+
```

A stack pointer identifies the current position within the structure.

The stack follows LIFO behavior:

```text
Last Address Pushed
        │
        ▼
First Address Popped
```

# BTB vs RAS

The Branch Target Buffer and Return Address Stack solve related but different problems.

| Structure | Primary Purpose |
|---|---|
| Branch Predictor | Predict branch direction |
| BTB | Predict branch target address |
| RAS | Predict function return address |

The RAS is particularly effective for call/return sequences because return addresses naturally follow a LIFO pattern.
